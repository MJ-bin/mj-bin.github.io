* `git status` 출력시 비ASCII 문자 깨짐
```sh
# 현재 레포만
git config --local core.quotepath false

# 시스템 전역
git config --global core.quotepath false
```
-> git이 파일명에 비ASCII 문자를 출력할때 옵션값이 true면 이스케이프 형태로 표시한다.
