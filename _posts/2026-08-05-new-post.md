* `git status` 출력시 비ASCII 문자 깨짐
```sh
# 현재 레포만
git config --local core.quotepath false

# 시스템 전역
git config --global core.quotepath false
```
-> git이 파일명에 비ASCII 문자를 출력할때 옵션값이 true면 이스케이프 형태로 표시한다.

* `branch1` 에서 `branch2` 가 분기된 상황에서, 부모 브랜치 `branch1` 에 커밋이 발생
```sh
git checkout {branch2}
git merge {branch1}
```
-> `branch1` 과 `branch2` 가 공통 부분에서 변화가 발생했을 경우엔 편집기를 통해 충돌을 해결한다.
-> 또한, rebase 를 사용하면 커밋기록을 깔끔하게 남길수 있지만, rebase 는 말그대로 브랜치의 시작점을 옮기므로 협업시 주의할것.
